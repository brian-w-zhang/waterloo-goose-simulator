# AI use

How generative AI is used in this repository (SE 390 course guide section 11).

## Tools

| Tool | Version | Used for |
|---|---|---|
| Claude Code (Anthropic) | model `claude-opus-5-5` | Writing pipeline, game and test code; running the verification harness; scoring viewpoint renders against reference photos (advisory only); drafting notes and review documents |
| Jev (TypeSafe AI) via the Vercel AI Gateway | `typesafe-ai/jev-1.14.0` | Optional in-game decisions for characters who give up a chase (`?jev=1`, off by default); answers are constrained to fixed options and recorded for replay |
| Grok Bot (xAI agent) | as recorded in `docs/plan/` AID statements | Collecting data and drafting the planning pack in `docs/plan/` |

## How AI output is checked before it lands

- Every AI-assisted commit carries an `Assisted-by: Claude:<model> [tools]` trailer. AI tools never add `Co-authored-by:`, `Generated-by:` or `Signed-off-by:`.
- Geometry and style claims are gated by the automated harness (`npm run verify`, doc `docs/plan/08-verification-and-self-checks.md`); the harness reads the packed world and real screenshots, and `verify:selftest` proves each gate fails on a deliberately broken world.
- Model-judged looks (`looks.json`) never pass a milestone on their own; Brian reviews the contact sheet and every commit.
- Library APIs are checked against the installed package source, not recalled from memory.
- No AI-generated images, meshes or textures: all graphics are generated by code from open data.
